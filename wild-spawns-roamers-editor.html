Rules (non-chaos)
No legendaries. Unown / Ditto / Smeargle never roll (they stay pinned in Artisan Cave). Levels on slots are kept — the slot's max level picks which BST bracket may roll.
Surf = Water/Flying, fish = Water. Underwater uses surf rules. Caves = Rock/Ground/Steel/Fighting/Dark/Poison, plus dual Grass types, plus dual Water types on land. New Mauville (power plant) = Electric. Forests = Bug/Grass/Flying/Ghost/Psychic/Dark. Desert = cave set + Flying, no Poison/Fighting. Meteor Falls + Victory Road = Dragon, pseudo-legendaries, Fighting, Dark. Mt Pyre = Ghost/Dark/Psychic. Magma Hideout = Fire only. Shoal Cave = all Ice (surf Ice/Water or Ice/Flying, fish Ice/Water). Sky Pillar = Flying with 450+ BST. Routes grass = Fire / Normal / Psychic / Flying / Bug / Dark / Electric only (Mt Pyre + forest grass keep their own sets) — Normal and Flying roll at 3x weight. Grass tables roll max 8 unique species, the other 4 slots repeat them.
Higher-level areas roll evolved forms of species placed on other maps once the slot's level allows it (level evolutions need their level; trade, stone, day/night and happiness evolutions need 30) — BST is ignored for those, never inside the same map.
Randomize ALL maps then places any missing evolution families, so all 365 non-legendary species stay catchable by catch or evolution (legendaries never roll — they're the roamers).
BST brackets by slot max level (a preference, not a cutoff — an empty bracket broadens outward; type and method rules never loosen) — 1-5: 150-200 · 4-8: 190-210 · 6-12: 190-215 · 8-14: 190-220 · 14-18: 210-230 · 18-22: 225-250 · 22-26: 245-300 · 26-30: 280-350 · 30-34: 340-410 · 34-38: 400-590 · 38+: 580-900.
